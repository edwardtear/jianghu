# 江湖一生 · One Life in the Jianghu

一款中英双语的武侠人生模拟器。生在何处，由天不由你；练功、比武、恋爱、闯荡，一年一年地活，史书会记下你的一生。

A bilingual (Chinese / English) wuxia life simulator in the spirit of BitLife: born where fate puts you, you train, fight, love and wander, one year at a time.

**Play:** https://edwardtear.github.io/jianghu/

- Pure HTML and JavaScript, no build step. Open `index.html` to play locally.
- Optional accounts, cloud saves and feedback through Firebase: see `SETUP.md` and `firebase-config.js`.
- `firestore.rules` holds the database security rules.
